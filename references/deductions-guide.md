# 七项专项附加扣除完整指南（2026 年最新）

> 政策依据：《个人所得税专项附加扣除暂行办法》（国发〔2018〕41号，2023年部分项目标准上调）
> 生效日期：2026-01-01 起适用

## 1. 子女教育

| 项目 | 标准 |
|------|------|
| 扣除标准 | 每孩每月 2,000 元（全年 24,000 元） |
| 适用条件 | 年满 3 岁至博士毕业的全日制学历教育期间 |
| 分配方式 | 父母各 50%，或一方 100%（选定后一年内不变） |
| 所需材料 | 子女学籍信息 |

## 2. 继续教育

| 项目 | 标准 |
|------|------|
| 学历继续教育 | 每月 400 元（最长 48 个月） |
| 职业资格 | 取得证书当年 3,600 元 |
| 适用条件 | 在中国境内接受的继续教育 |
| 分配方式 | 本人扣除（父母子女已不能重复享受） |

## 3. 大病医疗

| 项目 | 标准 |
|------|------|
| 扣除标准 | 年度自付超过 15,000 元部分，在 80,000 元限额内据实扣除 |
| 适用条件 | 医保目录范围内的自付部分 |
| 分配方式 | 本人/配偶/未成年子女均可（由实际负担方扣除） |
| 办理时间 | 仅在汇算清缴时扣除 |

## 4. 住房贷款利息

| 项目 | 标准 |
|------|------|
| 扣除标准 | 每月 1,000 元（全年 12,000 元） |
| 适用条件 | 首套住房贷款（以贷款合同为准），最长 240 个月 |
| 分配方式 | 夫妻双方约定，一方 100% |
| 注意 | 与住房租金**不能同时享受** |

## 5. 住房租金

| 项目 | 标准 |
|------|------|
| 直辖市/省会/计划单列市 | 每月 1,500 元 |
| 市辖区户籍人口 > 100 万 | 每月 1,100 元 |
| 市辖区户籍人口 ≤ 100 万 | 每月 800 元 |
| 注意 | 与住房贷款利息**不能同时享受** |

## 6. 赡养老人

| 项目 | 标准 |
|------|------|
| 独生子女 | 每月 3,000 元（全年 36,000 元） |
| 非独生子女 | 分摊每月 3,000 元，每人不超过 1,500 元 |
| 适用条件 | 父母年满 60 周岁 |
| 分配方式 | 均摊/约定/被赡养人指定（需签协议） |

## 7. 婴幼儿照护（2023年新增）

| 项目 | 标准 |
|------|------|
| 扣除标准 | 每孩每月 2,000 元（全年 24,000 元） |
| 适用条件 | 0-3 岁婴幼儿 |
| 分配方式 | 父母各 50%，或一方 100% |
