# 特殊收入类型税务处理

> 政策依据：《个人所得税法》第二条至第四条、《个人所得税法实施条例》
> 生效日期：2026-01-01 起适用

## 一、经营所得

| 项目 | 说明 |
|------|------|
| 适用税率 | 5%~35% 五级累进（与综合所得不同） |
| 计税方式 | 按年计算，收入总额减成本、费用及损失 |
| 常见人群 | 个体工商户、个人独资企业投资人、合伙企业个人合伙人 |
| 申报时间 | 次年 3月31日前 |

## 二、财产租赁所得

| 项目 | 说明 |
|------|------|
| 适用税率 | 20%（住房租赁优惠税率 10%） |
| 扣除标准 | 每次收入 ≤4000 元扣 800 元，>4000 元扣 20% |
| 常见场景 | 房屋出租、设备租赁 |
| 注意事项 | 需提供租赁合同、完税凭证 |

## 三、财产转让所得

| 项目 | 说明 |
|------|------|
| 适用税率 | 20% |
| 扣除标准 | 财产原值 + 合理费用 |
| 常见场景 | 股权转让、房产转让 |
| 优惠政策 | 满五唯一住房免征；上市公司股票转让暂免 |

## 四、利息、股息、红利所得

| 项目 | 说明 |
|------|------|
| 适用税率 | 20% |
| 扣除标准 | 无扣除，全额计税 |
| 优惠政策 | 国债利息免税；上市公司持股 >1年 股息免税 |
| 申报方式 | 支付方代扣代缴 |

## 五、偶然所得

| 项目 | 说明 |
|------|------|
| 适用税率 | 20% |
| 扣除标准 | 无扣除，全额计税 |
| 常见场景 | 中奖、中彩、抽奖 |
| 免税额度 | 单次 ≤10,000 元免税（福利彩票/体育彩票） |

## 六、劳务报酬所得（预扣预缴）

| 预扣预缴税率 | 预扣预缴应纳税所得额 |
|-------------|-------------------|
| 20% | ≤20,000 元 |
| 30% | 20,000~50,000 元 |
| 40% | >50,000 元 |

> 注：劳务报酬在汇算清缴时并入综合所得，适用 3%~45% 七级累进税率。
> 预扣预缴时按收入 ×80% 计算（即扣除 20% 费用）。
