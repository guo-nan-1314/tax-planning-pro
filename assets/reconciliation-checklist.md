# 汇算清缴操作 Checklist

> 办理时间：每年 3月1日 ~ 6月30日
> 工具：个人所得税 APP 或自然人电子税务局网页端

## 准备阶段

- [ ] 下载并注册"个人所得税" APP
- [ ] 确认个人信息（姓名、身份证号、手机号）
- [ ] 绑定银行卡（用于退税收款）
- [ ] 确认任职受雇信息

## 数据核对

- [ ] 核对工资薪金收入（与单位申报一致）
- [ ] 核对劳务报酬收入
- [ ] 核对稿酬收入
- [ ] 核对特许权使用费收入
- [ ] 核对已预缴税额

## 扣除填报

- [ ] 确认专项附加扣除是否完整（参照 deduction-checklist.md）
- [ ] 补报遗漏的扣除项
- [ ] 大病医疗支出是否填报？
- [ ] 商业健康险/企业年金等其他扣除是否填报？

## 年终奖优化

- [ ] 查看年终奖当前计税方式（单独/并入）
- [ ] **切换对比**：尝试两种方式，选择税额更低的
- [ ] 年终奖盲区检测：是否存在多发 1 元多交税的情况

## 提交申报

- [ ] 确认退税/补税金额
- [ ] 补税 ≤400 元可免补（选择豁免）
- [ ] 提交申报
- [ ] 退税：等待国库退库（通常 1-2 周）
- [ ] 补税：在 6月30日前完成缴纳
