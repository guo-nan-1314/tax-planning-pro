# 专项附加扣除自查清单

> 每年 12 月确认下一年度扣除信息，3-6 月汇算清缴时补报

## 子女教育

- [ ] 子女是否年满 3 岁？
- [ ] 扣除比例：各 50% 还是一方 100%？
- [ ] 年内是否有子女毕业/入学变化？

## 继续教育

- [ ] 本年度是否在读学历继续教育？
- [ ] 本年度是否取得职业资格证书？
- [ ] 学历继续教育是否超过 48 个月？

## 大病医疗

- [ ] 本人/配偶/子女是否有大额医疗支出？
- [ ] 医保目录内自付是否超过 15,000 元？
- [ ] 是否保留好医疗票据？（汇算清缴时扣除）

## 住房贷款利息

- [ ] 是否为首套住房贷款？
- [ ] 贷款是否仍在还款期内？
- [ ] 是否已超过 240 个月？
- [ ] 是否与配偶约定好扣除方？

## 住房租金

- [ ] 工作城市是否有自有住房？
- [ ] 是否签订正式租赁合同？
- [ ] 城市级别对应扣除标准（1500/1100/800）？
- [ ] 是否同时享受了住房贷款利息？（不可同时享受）

## 赡养老人

- [ ] 父母是否年满 60 周岁？
- [ ] 是否为独生子女？
- [ ] 非独生：分摊协议是否签署？每人 ≤1500？

## 婴幼儿照护

- [ ] 子女是否在 0-3 岁期间？
- [ ] 扣除比例：各 50% 还是一方 100%？
- [ ] 年内是否满 3 岁转子女教育？
